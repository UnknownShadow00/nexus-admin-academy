# V2 Service Desk catalogue roles

INC2501–INC2510 are the evidence-based converted simulation catalogue. The
legacy seed deliberately assigns every active scenario to every non-mentor as
an optional `simulation` assignment (`is_required=false`). These assignments
make the scenarios available for guided practice without turning them into ten
mandatory curriculum gates.

Only INC2503 is also bound to a V2 `service_desk` module assessment. It is the
required applied ticket for **IP Configuration & Basic Connectivity
Troubleshooting**. The other nine remain optional practice catalogue entries.
Creating artificial V2 module bindings for them would change the authored
curriculum rather than repair an omission.
