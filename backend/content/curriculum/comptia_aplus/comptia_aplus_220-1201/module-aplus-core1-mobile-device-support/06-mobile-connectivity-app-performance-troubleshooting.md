# Lesson 6 — Troubleshooting Mobile Connectivity, Apps & Performance

## 1. What is this?
The remaining mobile troubleshooting problems often look vague:
- poor/no connectivity
- malware/unwanted software
- unable to install new applications
- stylus does not work
- degraded performance
- overheating
- touch/cursor problems

The technician's job is to turn “my phone is broken” into a smaller, testable problem.

## 2. Why does an IT worker care?
Mobile support is easy to overreact to. **Factory reset** is not a professional first response to every sync, app, or performance problem. It destroys state and may create more work.

Use the troubleshooting habits CompTIA recommends even though the six-step methodology is not itself a numbered 220-1201 objective:
identify → form/test a theory → plan/act → verify → document.

## 4. What you actually need to remember
### Poor/no connectivity
Isolate the path:
- does Wi-Fi work?
- does cellular work?
- can another device use the same Wi-Fi?
- is airplane mode/radio state correct?
- is SIM/eSIM/service status normal?
- is MDM/policy influencing the connection?

### Unable to install an app
Check:
- storage
- internet access
- OS/app compatibility
- app store/work account
- permissions
- MDM/policy restrictions

### Malware / unwanted application
Indicators can include:
- unknown apps
- aggressive pop-ups/redirects
- sudden unusual resource use
- unexpected settings changes
- degraded performance after an untrusted install

Do not disable security permanently to make a symptom disappear. Follow the organization's mobile security procedure and escalate when needed.

### Degraded performance / heat
Look for:
- thermal throttling or overheating
- low storage
- runaway/background apps
- old/degraded battery
- weak cellular signal causing higher radio use
- pending OS/app problems
- management/security software issues

### Stylus/touch
If finger touch works but a stylus does not, check compatibility, charge, pairing, and settings before declaring the digitizer dead.

## 5. At work
A field coordinator reports two symptoms: the phone charges only at an angle and corporate mail stopped syncing. Treat these as **two evidence streams**. The port may be physically damaged while the mail problem may be account, connectivity, app, or MDM-related. A factory reset is not justified until simpler, safer evidence-based checks fail and authorization exists.

## 6. Commands / Tools
- Wi-Fi/cellular toggles and status
- app storage/version/permissions
- company app catalog/MDM status
- device storage and battery/thermal information
- security scan or approved mobile security workflow
- ticket notes and verification evidence

## 7. Interview / Explain
**Prompt:** “A phone has no internet. How do you avoid guessing?”

A strong answer tests Wi-Fi and cellular separately, compares with another device/network, checks radio/SIM/policy state, changes one thing at a time, and verifies the original symptom.
