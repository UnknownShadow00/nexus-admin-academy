# 1. What is this?
A+ expects you to recognize basic SOHO setup, common internet connection types, network-size categories, and the technician tools used to inspect links.

# 2. Why does an IT worker care?
Many entry-level tickets are "new desk has no link," "home user cannot connect to VPN," or "which ISP handoff is this?" Correct tool choice can prove the problem quickly without swapping random equipment.

# 3. Watch / Read
**Required:** Professor Messer — *Internet Connection Types* and *Network Tools (220-1201)*.  
**Optional:** *Network Types* for LAN/WAN/PAN/MAN/SAN/WLAN terminology.

# 4. What you actually need to remember
- SOHO basics: correct WAN/LAN connections, DHCP where appropriate, strong wireless configuration, correct IP/subnet/gateway/DNS, and documented changes.
- Public vs private IPv4, IPv6, static vs dynamic, and APIPA are **Review from Module 1**.
- Internet access may use fiber, cable, DSL, satellite, cellular, or WISP.
- LAN/WLAN cover local networks; WAN spans larger geographic scope; PAN is personal; MAN is metropolitan; SAN is storage-focused.
- **Cable tester:** continuity/wiring faults.
- **Toner + probe:** trace an unlabeled copper cable.
- **Punch-down tool:** terminate conductors on a punch-down block/patch panel.
- **Crimper/stripper:** prepare/terminate supported copper cabling.
- **Wi-Fi analyzer:** radio/channel evidence.
- **Loopback plug:** test a compatible interface's transmit/receive path.
- **Network tap:** observe/capture traffic in an authorized environment.

# 5. At work
A wall jack has no link and labels are missing. A toner/probe helps locate the cable; a cable tester then checks whether the run is wired correctly. Those are different questions and different tools.

# 6. Commands / Tools
Use the physical tools above. For IP evidence, reuse Module 1 commands rather than treating a cable tester as an IP-layer diagnostic.

# 7. Interview / Explain
Explain the difference between a toner/probe and cable tester.
