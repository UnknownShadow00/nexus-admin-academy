# 1. What is this?
Different printer technologies fail differently. Inkjet uses liquid ink and print heads; direct thermal uses heat-sensitive media; impact printers physically strike a ribbon against multipart/continuous paper.

# 2. Why does an IT worker care?
Applying laser-printer logic to every printer wastes time. There is no toner cartridge to replace in a direct thermal receipt printer, and an impact printer may need a ribbon/tractor-feed adjustment rather than a print-head cleaning cycle.

# 3. Watch / Read
**Required:** Professor Messer — *Inkjet Printers*, *Thermal Printers*, and *Impact Printers*.  
**Optional:** the matching maintenance videos for each technology.

# 4. What you actually need to remember
**Inkjet**
- cartridges/ink, print head, carriage/belt, rollers/feeders;
- clean print heads and calibrate according to vendor procedure;
- dried/clogged ink can create missing/streaked output.

**Thermal**
- correct thermal paper/media, feed assembly, heating element;
- keep heating path clean and protect paper from excessive heat/storage conditions;
- no ink/toner in direct thermal printing.

**Impact**
- ribbon, print head/pins, tractor/feed mechanism, multipart/continuous paper;
- replace worn ribbon/print head/paper and align feed path according to procedure.

# 5. At work
A receipt printer produces blank paper after someone loaded ordinary copier paper. Before replacing the printer, verify it is a direct thermal model and use the correct thermal media orientation/type.

# 6. Commands / Tools
Printer self-test/status, visual inspection, vendor cleaning/calibration procedure, correct consumables/media.

# 7. Interview / Explain
Compare one maintenance task for inkjet, thermal, and impact printers.
