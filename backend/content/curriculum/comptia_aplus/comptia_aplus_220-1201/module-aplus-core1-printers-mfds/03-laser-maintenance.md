# 1. What is this?
Laser printers use toner, imaging/transfer components, rollers, and a hot fuser to create output. A+ maintenance includes replacing toner and maintenance kits, calibration, and cleaning according to manufacturer procedure.

# 2. Why does an IT worker care?
Laser printers are common in offices and can be expensive. Technicians need to distinguish an empty/defective consumable, paper problem, worn maintenance component, or output defect without touching hot/high-voltage areas carelessly.

# 3. Watch / Read
**Required:** Professor Messer — *Laser Printer Maintenance (220-1201)*.

# 4. What you actually need to remember
- Replace toner when indicated and verify the correct cartridge/model.
- Maintenance kits commonly include wear components such as rollers/fuser-related parts depending on model.
- Allow the **fuser to cool** before service; follow manufacturer safety instructions.
- Calibrate when required after consumable/component changes or print-density/color issues.
- Clean using the manufacturer-approved procedure/materials; loose toner requires appropriate handling.
- Paper type/condition can cause feed and print-quality symptoms.

# 5. At work
A laser printer has faded output immediately after a new toner installation. Verify cartridge seating/seals/compatibility and run the approved calibration/diagnostic process before replacing unrelated network hardware.

# 6. Commands / Tools
Printer supplies/status page, event/error codes, maintenance counter, configuration/test pages, and vendor service documentation.
