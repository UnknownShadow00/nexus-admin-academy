# Cloud Deployment & Service Models

## 1. What is this?
Cloud deployment models describe **who uses the environment**: public, private, hybrid, or community. Service models describe **how much of the stack the provider manages**: IaaS, PaaS, or SaaS.

## 2. Why does an IT worker care?
The support boundary changes by model. A SaaS user cannot repair the provider’s OS, while an IaaS administrator may manage the guest OS and applications.

## 4. What you actually need to remember
- Public = provider cloud shared across customers.
- Private = dedicated to one organization.
- Hybrid = coordinated private + public cloud use.
- Community = shared by organizations with common requirements.
- IaaS = infrastructure; customer manages more OS/apps.
- PaaS = managed platform/runtime.
- SaaS = finished application.

## 5. At work
A user cannot sign in to hosted email. Troubleshoot the account/client/service status, not a nonexistent local mail server.

## 6. Commands / Tools
Use provider status pages, authorized tenant/admin portals, client tests, and ownership/escalation information.

## 7. Interview / Explain
Give one workplace example of SaaS, PaaS, and IaaS and explain ownership at a high level.
