# Cloud Characteristics & Support Decisions

## 1. What is this?
Cloud services use concepts such as metered utilization, ingress/egress, elasticity, availability, file synchronization, multitenancy, and shared/dedicated resources.

## 2. Why does an IT worker care?
These become real support symptoms and cost/ownership questions. A sync problem is not automatically an outage; elasticity is not availability; sync is not backup.

## 4. What you actually need to remember
- Metered utilization measures/charges consumption.
- Elasticity changes capacity with demand.
- Availability is whether the service is reachable/usable.
- File synchronization keeps copies aligned; it is not an independent backup.
- Multitenancy shares infrastructure while isolating tenants logically.
- Ingress enters a service; egress leaves it.
- Shared vs dedicated resources affect isolation, cost, and capacity.

## 5. At work
A cloud portal shows the current file but one laptop is stale. Investigate that client’s sync/account state before declaring a provider outage.

## 6. Commands / Tools
Check service status, sync client state, timestamps, storage quota, connectivity, and account/licensing state while protecting credentials/data.

## 7. Interview / Explain
Explain elasticity vs availability and why file synchronization is not a backup strategy.
