# Managed Mobile Device Security & BYOD Boundaries

## 1. What is this?
Protect corporate and BYOD mobile devices with encryption, locks, profiles, patching, MDM, remote actions, and clear ownership boundaries.

## 2. Why does an IT worker care?
Phones, browsers, Wi-Fi, and small routers sit directly between users and company data. The support technician must distinguish ordinary configuration failure from a security problem without bypassing management, encryption, certificates, or policy.

## 3. Watch / Read
Complete the required resource **resource.aplus.m14.mobile_device_security**. Use supplemental resources only where another vendor-specific view is useful.

## 4. What you actually need to remember
- Modern managed mobile security includes device encryption, strong screen lock/biometrics, current OS/apps, and approved endpoint/security controls.
- MDM can enforce profiles, passcode requirements, certificates, Wi-Fi/VPN settings, app policy, remote lock/wipe, and compliance rules.
- BYOD and corporate-owned devices have different privacy, ownership, and wipe boundaries.
- Remote wipe should be used only under approved policy because it can be destructive.
- Device locator, backup, failed-login limits, and recovery procedures matter before loss or compromise occurs.
- Do not remove a management profile merely to bypass a restriction.

## 5. At work
- Verify ownership and management status before wipe/reset/profile changes.
- Record whether a device is compliant, encrypted, current, and backed up before destructive recovery.

## 6. Commands / Tools
- MDM/endpoint portal
- Device security/passcode settings
- OS update page
- Configuration profile/certificate status
- Backup/locator status

## 7. Interview / Explain
Explain the difference between a BYOD security decision and a corporate-owned-device decision.
