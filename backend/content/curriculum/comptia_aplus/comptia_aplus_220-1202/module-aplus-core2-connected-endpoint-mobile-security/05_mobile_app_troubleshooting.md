# Mobile OS & Application Troubleshooting

## 1. What is this?
Troubleshoot mobile apps, updates, connectivity, storage, performance, battery, sync, and OS problems without jumping immediately to a factory reset.

## 2. Why does an IT worker care?
Phones, browsers, Wi-Fi, and small routers sit directly between users and company data. The support technician must distinguish ordinary configuration failure from a security problem without bypassing management, encryption, certificates, or policy.

## 3. Watch / Read
Complete the required resource **resource.aplus.m14.troubleshooting_mobile**. Use supplemental resources only where another vendor-specific view is useful.

## 4. What you actually need to remember
- Start with the exact symptom, affected app(s), recent changes, available storage, network state, OS/app versions, and scope.
- Force-close/restart, verify connectivity, update the app/OS, and check storage/permissions before destructive actions.
- One failing app suggests an app/account/configuration problem more than a full device failure.
- Multiple apps failing after an OS update may point to OS compatibility, storage, profile, or network issues.
- Battery drain and overheating require separating expected high usage from runaway apps, poor signal, background activity, or hardware problems.
- Back up before destructive reset/reinstall when possible and authorized.

## 5. At work
- Reproduce the original symptom after each meaningful change.
- Do not erase a device before preserving needed data and verifying less-destructive options.

## 6. Commands / Tools
- App settings/storage/permissions
- OS update and storage status
- Wi-Fi/cellular state
- Battery usage
- Sync/account status
- Approved backup/reset tools

## 7. Interview / Explain
Walk through a safe sequence for an app that opens and immediately crashes.
