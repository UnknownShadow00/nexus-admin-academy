# Browser Security, Certificates, Downloads & Extensions

## 1. What is this?
Keep browsers trusted, patched, and resistant to unsafe downloads, extensions, pop-ups, credential theft, and certificate problems.

## 2. Why does an IT worker care?
Phones, browsers, Wi-Fi, and small routers sit directly between users and company data. The support technician must distinguish ordinary configuration failure from a security problem without bypassing management, encryption, certificates, or policy.

## 3. Watch / Read
Complete the required resource **resource.aplus.m14.browser_security**. Use supplemental resources only where another vendor-specific view is useful.

## 4. What you actually need to remember
- Install browsers and extensions from trusted sources and keep them patched.
- Verify downloads with vendor-provided hashes/signatures when the workflow supports it.
- HTTPS and a valid certificate protect the connection to the site; certificate warnings are evidence that should be investigated, not clicked through automatically.
- Extensions can read or modify browser data depending on permissions. Use only approved extensions.
- Pop-up blockers, safe-browsing/reputation features, secure DNS, password managers, and appropriate privacy settings add protection.
- Clearing cache/cookies can troubleshoot site state, but it is not a universal security fix.

## 5. At work
- Capture the exact certificate warning/URL/time before changing trust settings.
- Do not install a 'codec', extension, or browser update from an unsolicited pop-up.

## 6. Commands / Tools
- Browser update/about page
- Certificate/site information
- Extension manager
- Download hash/checksum tools where approved
- Proxy/DNS browser or OS settings

## 7. Interview / Explain
A user receives a certificate warning on a business site. Explain what you check before proceeding.
