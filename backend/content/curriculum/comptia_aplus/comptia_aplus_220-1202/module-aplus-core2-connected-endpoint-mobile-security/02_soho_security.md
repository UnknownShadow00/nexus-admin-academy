# Securing SOHO Routers & Small Networks

## 1. What is this?
Harden a small-office/home-office router using controls that actually reduce risk.

## 2. Why does an IT worker care?
Phones, browsers, Wi-Fi, and small routers sit directly between users and company data. The support technician must distinguish ordinary configuration failure from a security problem without bypassing management, encryption, certificates, or policy.

## 3. Watch / Read
Complete the required resource **resource.aplus.m14.soho_security**. Use supplemental resources only where another vendor-specific view is useful.

## 4. What you actually need to remember
- Change default administrator credentials and keep router firmware current.
- Use WPA2/WPA3 with a strong credential; disable obsolete security modes.
- Disable unnecessary remote administration, UPnP, and exposed services when policy/use does not require them.
- Guest networks isolate untrusted/visitor devices from trusted internal devices.
- Content filtering, firewall rules, and secure DNS can reduce risk when appropriately configured.
- MAC filtering and hiding an SSID may reduce casual visibility but are not strong authentication controls.

## 5. At work
- Back up known-good settings before major router changes when the device supports it.
- Preserve required business features; hardening should not randomly block necessary services.

## 6. Commands / Tools
- Router management interface
- Firmware/version page
- Wireless security settings
- Guest network and firewall settings
- Configuration backup/restore

## 7. Interview / Explain
Name five meaningful SOHO hardening steps and one weak 'security by obscurity' control.
