# Cloud Productivity, Sync, Identity & Licensing Support

## 1. What is this?
Cloud productivity suites combine email, storage/sync, collaboration applications, identity synchronization, and license assignment. The user may have one account but several independent client, sync, and entitlement states.

## 2. Why does an IT worker care?
“Cloud app broken” is too broad. A technician should separate sign-in, license, sync-folder configuration, local client state, collaboration app behavior, connectivity, and provider-wide service scope.

## 4. What you actually need to remember
- Cloud productivity can include email, storage, spreadsheets, videoconferencing, presentations, word processing, and instant messaging.
- Identity synchronization keeps identity information consistent across connected services/directories.
- License assignment controls whether a user is entitled to a product/service.
- Sync/folder settings determine what local folders/files synchronize.
- A current web copy plus one stale client points toward that client/account/sync state, not automatically a provider outage.
- A successful sign-in does not prove a license is assigned to every application.

## 5. At work
A replacement laptop can sign in to web email, but the desktop suite reports “unlicensed.” Check the assigned entitlement and account identity before repeatedly reinstalling the application.

## 6. Commands / Tools
Authorized admin/license portal, client account/status UI, sync-client status/errors, provider status page, browser test, and documented service ownership.

## 7. Interview / Explain
Explain how you would separate a local sync problem from a licensing or provider-wide problem.
