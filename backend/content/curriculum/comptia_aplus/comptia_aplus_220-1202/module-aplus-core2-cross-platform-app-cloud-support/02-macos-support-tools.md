# macOS Support Tools, Backups & Security Features

## 1. What is this?
macOS includes built-in tools for disks, encryption, application recovery, search, credentials, backups, updates, and settings. A+ expects recognition of tools such as Disk Utility, FileVault, Terminal, Force Quit, Time Machine, Keychain, Spotlight, Finder, Dock, Mission Control, iCloud, and Continuity.

## 2. Why does an IT worker care?
The correct tool prevents unnecessary reinstalls. A frozen application may need Force Quit; a storage issue may require Disk Utility evidence; a missing historical file may be a Time Machine question; full-disk encryption is a FileVault question.

## 4. What you actually need to remember
- Time Machine = macOS backup/recovery feature; it is not the same as FileVault.
- FileVault = full-disk encryption.
- Keychain stores credentials/certificates securely for the user.
- Force Quit is for an unresponsive application, not a substitute for diagnosing repeated crashes.
- Disk Utility provides disk/volume evidence and repair options.
- System Settings controls networks, displays, printers/scanners, privacy, accessibility, and other settings.
- Apply approved updates/security responses; do not install beta software on production endpoints without authorization.

## 5. At work
A Mac user accidentally overwrote a document yesterday. Check whether a backup exists before experimenting with destructive recovery steps.

## 6. Commands / Tools
