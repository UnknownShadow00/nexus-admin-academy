## Look before making a change

An **application** is software the user opens to do work. Its **state** is what is happening now: open, closed, showing a message, or waiting. An **error message** is a clue; write its visible wording or a safe summary, but do not treat it as a diagnosis. An **approved application** is software the workplace allows. A **process** is an application or background task currently running; seeing one does not prove it is healthy or broken.

Use one appropriate read-only place first. **File Explorer** shows the supplied file and folder path. **Task Manager** can show whether the affected application is listed, but do not end a task. **Settings** can show a Windows option, but do not change it. The affected application can show its current window or message, but do not close it when work is unsaved. If you cannot safely inspect a clue, record that limit and ask for guidance. Command Prompt can display typed commands, but this stage requires no command entry.

## Short note-writing practice

Imagine a user says a document is missing and a browser is acting oddly. Write five short lines:

- **Reported:** What the user said, without changing it into a diagnosis.
- **Checked:** The approved path and one read-only application or Windows view you actually inspected.
- **Found:** Only what was visible, including the signed-in context if relevant.
- **Verified / Not verified:** Say what the evidence or user actually confirmed and what remains uncertain.
- **Next step:** An authorized check or escalation.

Do not put a password, private document content, personal address, or unredacted account name into a screenshot or note. Crop or cover unrelated details before uploading evidence. Keep any unsaved work open and ask the user to save it before a disruptive step.

Open the tools picture and match each view to its job. The checkpoint asks which observation to make before a change. The guided practical then asks you to perform those observations on an approved Windows computer and submit redacted evidence for mentor review.
