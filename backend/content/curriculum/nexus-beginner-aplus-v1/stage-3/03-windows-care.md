## Choose the right place

**Settings** changes how Windows or an application behaves. **File Explorer** finds files and folders. **Task Manager** shows running applications and basic activity. Seeing a program in Task Manager does not prove it is broken; do not end someone's work without asking.

An **installation** adds an application. **Uninstalling** removes one. Both may need permission, and removal might affect someone else's work. Do not install software from an unknown link. Ask what is approved for the workplace.

## Restart, shutdown, update

**Restart** closes programs and starts Windows again. **Shutdown** turns the computer off. An **update** can fix bugs or improve security, but it may take time and require a restart. Before restarting or updating a work computer, ask the user to save their work and check whether the timing is okay. Follow your workplace's update process.

Open the Windows tools picture, then choose a safe next action in the interaction. The checkpoint asks you to separate a setting from a file and to protect unsaved work.

## Why this matters at work

“Just restart it” can erase unsaved work. A good technician checks who is affected, what is open, and whether a change is authorized.
