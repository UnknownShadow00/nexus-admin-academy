## Accounts and permission

A **user account** tells Windows who is signed in. A **standard user** can do everyday work. An **administrator** can make wider system changes, such as installing software for everyone. Having administrator access does not mean every change is safe or approved. **Permissions** are rules about who may open or change something. Ask for help if access is denied; do not use someone else's account.

## Finding a file

**File Explorer** is the Windows application for finding files and folders. A **path** is an address that shows where a file is stored. For example, `Documents > Notes > plan.txt` means the file `plan.txt` is inside the Notes folder, inside Documents. The part after the last separator is the file, not an application.

Open the account-and-folder picture, then put the steps for finding a file in order. The checkpoint asks what you can safely do when access is denied.

## One small preview

Some technicians use typed commands later. The harmless Windows command `whoami` displays the account currently running it. If it shows `LAPTOP-17\Sam`, `Sam` is the account name. You only need to recognize that meaning now; you do not need to open a command window or run it.

## Why this matters at work

The same device may have several user accounts. Ask which person is affected before changing settings or searching for a file.
