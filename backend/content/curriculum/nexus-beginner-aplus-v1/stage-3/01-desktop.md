## What is an operating system?

An **operating system (OS)** is the main software that starts the computer, helps applications run, and manages files and connected devices. **Windows** is one operating system. **macOS** and **Linux** are others. Here we focus on Windows; you do not need to learn the others yet.

When you sign in to Windows, you usually see the **desktop**: a main screen with a taskbar, a Start menu, and open application windows. The **Start menu** helps you find applications and settings. The **taskbar** shows open applications and lets you switch between them. A web browser is an application running *on* an operating system; it is not the operating system itself.

Open the desktop picture, then identify which item is the operating system in the interaction.

## Why this matters at work

When someone asks for help, ask which device and operating system they are using. The same application can look different on Windows, macOS, or a phone.
