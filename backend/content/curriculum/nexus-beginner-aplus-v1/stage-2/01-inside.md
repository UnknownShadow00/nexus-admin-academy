## Follow one action

You type a letter on a keyboard (**input**). The computer follows instructions (**processing**). The letter appears on the screen (**output**). While you work, the computer holds active information in short-term **memory**. When you save the document, it goes to **storage** so it remains after power is off.

## Meet the parts by what they do

The **central processing unit (CPU)** follows instructions and processes information. **Random Access Memory (RAM)** is short-term working space. RAM is cleared when power is off. A **solid-state drive (SSD)** is one kind of storage; it keeps saved files when power is off. The **motherboard** is the main board that connects these parts. The **power supply** provides electrical power. None of these names tells you whether a file is safe to delete.

Open the simple component picture, then match each part to its job. You do not need model numbers, speeds, or sizes yet.

## Why this matters at work

“The computer is slow” is only a symptom. Knowing what each part does helps you ask better questions before changing anything.
