## 1. What is this?

Windows triage turns a symptom into scope, timeline, evidence, a tested theory,
a low-risk change, verification, and documentation.

## 2. Why does an IT worker care?

Restarting or reinstalling may hide evidence. A repeatable process finds root
cause while protecting user data and service.

## 3. Watch / read

- Microsoft — Windows troubleshooting documentation. *(required)*

## 4. What you need to remember

- Record exact symptom/error, when it began, changes, frequency, and scope.
- Check backup/recovery and approval before risky changes.
- Establish and test one theory with evidence.
- Escalate when data, security, hardware safety, or authorization demands it.
- Verify the user's original task and document the result.

## 5. Real workplace example

One app crashes for one user after an update. That scope leads to app/profile
evidence before an OS reinstall.

## 6. Commands / tools

Problem Steps Recorder/screenshots where policy permits, Reliability Monitor,
Event Viewer, Task Manager, ticket timeline, and vendor known-issue notes.

## 7. Interview / example

**What do you ask first?** Exact symptom, impact/scope, timing, recent changes,
reproducibility, error text, and actions already tried.
